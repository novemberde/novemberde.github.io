## Summary

### 주요 발표 내용

기본 빌딩 블록 강화: AWS는 컴퓨팅, 스토리지, 데이터베이스와 같은 기본적인 클라우드 서비스에 더욱 집중하는 모습을 보였습니다. 특히, 4세대 Graviton 칩을 예고하며 데이터베이스 및 웹 애플리케이션 구동 시 성능 향상을 강조했습니다. Amazon S3 테이블 기능 추가로 4K 데이터 처리를 위한 기능이 개선되었고, 글로벌 애플리케이션을 위한 멀티 리전 액티브-액티브 DB가 다수 발표되었습니다.

생성형 AI의 발전: 생성형 AI는 새로운 빌딩 블록으로 자리매김하고 있으며, AWS는 이를 위한 다양한 서비스와 도구를 제공합니다. AWS Trainium 2 칩 기반의 EC2 Trn2 인스턴스는 생성형 AI 추론에 특화되어 있으며, Amazon Bedrock은 다양한 파운데이션 모델과 기능을 제공합니다. Amazon Nova 모델은 다양한 크기와 기능을 제공하여 사용자의 요구에 맞는 선택이 가능하며, 이미지 및 비디오 생성 모델도 새롭게 선보였습니다.

소프트웨어 개발 지원: 생성형 AI는 소프트웨어 개발 현장에도 큰 영향을 미치고 있으며, AWS는 Amazon CodeWhisperer 서비스를 통해 개발을 지원합니다. CodeWhisperer는 소스 코드 생성, 레거시 코드 변환, 인프라 코드 생성 등 다양한 기능을 제공하며, 소프트웨어 개발의 모든 단계에서 활용할 수 있습니다. 또한, Amazon Q Developer는 기존 레거시 앱 코드를 변환해 주는 기능을 제공하여 개발 효율성을 높입니다.

### 주요 서비스 및 기능

| 서비스/기능 | 설명 | 특징 |
|------------|------|------|
| Graviton 4 | AWS의 차세대 실리콘 칩 | 이전 세대 대비 성능 향상, 다양한 인스턴스 타입 제공 |
| Amazon S3 테이블 | S3에 구현된 Apache Iceberg 테이블 | 빠른 쿼리 처리량, 높은 초당 트랜잭션 제공 |
| EC2 Trn2 인스턴스 | AWS Trainium 2 칩 기반의 EC2 인스턴스 | 생성형 AI 추론에 특화, 높은 가격 대비 성능 |
| Amazon Nova | AWS의 새로운 파운데이션 모델 | 다양한 크기 및 기능 제공, 멀티모달 모델 지원 |
| Amazon CodeWhisperer | AWS의 코딩 도우미 서비스 | 소스 코드 생성, 레거시 코드 변환, 코드 리뷰 기능 제공 |
| Amazon Q Developer | 레거시 앱 코드 변환 기능 | 기존 프로젝트 업데이트 지원, 개발 효율성 향상 |
| EKS 자동 모드 | 쿠버네티스 클러스터 자동 생성 기능 | 간편한 클러스터 설정, 온프레미스 물리 장비 활용 지원 |
| 람다 스냅 스타트 | 람다 함수 초기 구동 속도 향상 기능 | Java, Python, .NET 지원, 빠른 함수 실행 |
| SageMaker 유니파이드 스튜디오 | 통합된 데이터 과학 환경 | 데이터 소스, 전처리, 분석, AI/ML 기능을 한 곳에서 관리 |

### 추천 세션

- 서버리스 세션: 람다 출시 10주년을 기념하여 서버리스 아키텍처의 최적화 방안을 다룹니다.
- EKS 오토 모드 세션: EKS 자동 모드의 필요성, 장점 및 작동 방식을 자세히 설명합니다.
- Amazon Reviews & Highlights: 생성형 AI를 커머스 서비스에 접목한 아마존닷컴의 사례를 소개합니다.
- 이 외에도 AWS re:Invent 온디맨드 영상 페이지에서 다양한 녹화 영상을 분야별로 시청할 수 있습니다.
